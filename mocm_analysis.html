How It Works
1
Fetch the Latest Data
Reads the latest PHU MOCM submissions for every form.

2
Clean Resubmissions
Keeps one record per facility per form: the one with the latest date and time submitted. Earlier ones are removed whatever their status. Submission dates later than the server receipt have their day and month swapped back.
3
Scoring
Each form is scored as points earned divided by points possible, times 100. On Forms D to J every good practice question is worth one point, and a question that was skipped or did not apply is left out, so it never counts against a PHU. Form A is the facility profile and is not scored.

4
Completeness
Counts which of the nine PHU forms each facility has, by district, so you can see which facilities sent all forms, which sent some, and what is missing.
5
Outputs
Key findings naming the PHUs and the areas that need improvement, then bar and pie charts and tables for every form, the score bands and the facility lists, on screen and as a Word document and a PowerPoint deck.
