Use Case 21: Finance Data Management, Analysis and Reporting (Data, Dashboard and Reports) NMCP finance and programme management teams. Manage and analyse malaria programme finance data and produce reports. Provide a dedicated finance module for data management, dynamic dashboards, analysis, reporting and downloads. Finance information is available in a structured format for monitoring, analysis and programme reporting.

Source: NMDR Functional Use Cases, NMCP SM&E Unit, March 2026 (Table 10.0, Finance).

How it works in the NMDR

Step 1

Select the period

Choose the financial period to review, then click Run Pipeline.

Step 2

Data fetching and automated analytical pipelines

The pipeline loads the finance data into the finance module, organises it and runs the analysis for the selected period.

Step 3

Output

A finance dashboard with the analysis for the period, together with reports and data downloads for monitoring and programme reporting.

Status

Written up, not yet configured

This use case is written up from the NMCP document. The steps above show where the screenshots go, and the live output will be added when it is configured.
